# OpenSRO → Aion 4.8 region mapping: Jangan / Mangyang

Offline tool `tools/silkroad/map_opensro_regions.py` maps actual source spawn coordinates to **verified** existing Aion map coordinates.

Input: JSON generated by `import_opensro_textdata.py`, and a separate user-verified JSON file:

```json
{
  "schema_version": 1,
  "regions": {
    "SRO_REGION_ID_AS_DECIMAL_STRING": {
      "verified": true,
      "aion_world_id": 123,
      "sro_anchor_xyz": [0, 0, 0],
      "aion_anchor_xyz": [0, 0, 0],
      "scale": 1
    }
  }
}
```

**Illustrative schema only:** world ID 123 and coordinates above are not verified. Replace them with actual values. Confirm Aion world IDs against `game-server/data/static_data/world_maps.xml` or loaded `DataManager.WORLD_MAPS_DATA`. Find Mangyang's source region/position from the exported `npcpos.txt`.

```sh
python tools/silkroad/map_opensro_regions.py --source build/opensro-world.json --mapping verified-regions.json --output build/opensro-aion-mapped.json
python -m unittest discover -s tools/silkroad -p 'test_*.py'
```

Coordinates are transformed by translation and uniform scale only; terrain, rotation, collision and geometry are NOT recreated. Unmapped regions retain null Aion positions. Every spawn is disabled and runtime import is not implemented. The candidate Mangyang Aion NPC ID 210671 still requires template/client verification. No production changes or proprietary map assets.
